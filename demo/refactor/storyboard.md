# Refactor workshop walkthrough

Creative direction: the open workshop turns a concrete duplication problem into
two executable plans. Calm product recording, real controls, no splash screen.
Uses the same brag-guided CDP capture and local GIF encoder as afm-ux-demo.

Audience: a developer who has received findings and needs to decide what to do.
Hook: four channels, one price. Main promise: see the change before approving it.
Proof: real diagram, component/connection diff, actual plan export. The checkout
architecture is explicitly illustrative; no production analysis is claimed.
Agent discussion is a captured real Codex reply to this fixture, replayed through
the workshop publication API. It is not a recording of a full AFM analysis run.

## Storyboard

1. Open workshop, first proposal; read Why / Before / After (4 s).
2. Ask how to preserve rounding; show the captured agent answer (5 s).
3. Create “01 · Общий расчёт”; add the first proposal (4 s).
4. Next arrow, read the channel consolidation, play the transformation (6 s).
5. Open 3D, rotate the same before/after graphs; highlight changed links and
   removed copies, making the shared central pricing module visible (6 s).
6. Create “02 · Подключение каналов”; review its dependency and checks (4 s).
7. Approve, save checkpoint, show the actual exported two-plan package (6 s).

The final edit is 42.25 seconds, longer than the usual 25-second brag edit because
reading the discussion and final plans is part of the requested demonstration.
All holds keep the full UI readable. Captions identify the example and explain
the action; they do not invent controls, decisions, replies or test results.
No audio. GIF plus MP4 and a settled poster; source captures stay outside Git.

Render validation: browser exceptions, UI events, selected plans, export paths,
GIF dimensions/duration/size and contact-sheet visual inspection.
