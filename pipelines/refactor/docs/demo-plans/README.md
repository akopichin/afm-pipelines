# Plans exported by the workshop demo

These files were generated by the real workshop exporter from the illustrative
checkout architecture used in the walkthrough. They are examples, not tasks
for the AFM codebase and not a claim that production source was analyzed.
No application code was changed.

1. [Shared pricing](01-plan-2.md): capture existing behavior, extract
   `CalculatePrice`, then switch the HTTP handler to it.
2. [Connect the channels](02-plan-3.md): compare policies, switch CSV import,
   subscriptions and partner checkout, then remove the three copies.

The second plan requires the first. Each plan includes verification, risks,
and architecture snapshots. [index.json](index.json) records the exact order
and dependency IDs. The exported plan text uses the demonstration's Russian
language; this index explains the sample for English-language readers.
